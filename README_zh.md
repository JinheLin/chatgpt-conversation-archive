# ChatGPT Conversation Archive

[English](README.md) | 简体中文

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

输入一个 ChatGPT 对话链接，阅读完整对话，在本地保存划线和评论，并导出带问题目录的 PDF 或单文件 HTML。无需启动服务器、安装 Node.js 或配置 API Key。

插件文案跟随 Chrome 界面语言：简体中文显示中文，其他语言（包括繁体中文）显示英文。导出页按钮、进度及错误提示、导出文件的目录和导航标签均遵循该规则。对话正文保留原语言。

## 快速开始

### 1. 获取项目

```bash
git clone https://github.com/JinheLin/chatgpt-conversation-archive.git
```

也可以在 GitHub 点击 **Code → Download ZIP**，下载后解压。运行扩展不需要安装任何依赖。

### 2. 加载与使用

1. 保留完整的 `chatgpt-conversation-archive` 项目文件夹（包含 `vendor`）。
2. 在 Chrome 中打开 `chrome://extensions/`，开启右上角「开发者模式」。
3. 点击「加载未打包的扩展程序」，选择包含 `manifest.json` 的项目根目录。
4. 在同一 Chrome 用户配置中登录 ChatGPT。
5. 点击 Chrome 右上角「扩展程序」菜单中的 **ChatGPT Conversation Archive**，也可将扩展固定到工具栏后点击图标。在 ChatGPT 对话页使用工具栏入口，会自动读取当前对话。
6. 从对话页进入并携带链接时，阅读器会自动填入链接，优先打开已保存的本地快照；没有快照时读取并保存完整对话。未携带链接，或从 ChatGPT 首页及其他网站打开插件时，输入 `https://chatgpt.com/c/…` 对话链接，再点击「读取完整对话」。
7. 百分比进度条依次显示连接、读取、校验、附件和排版阶段，更新时平滑移动。服务端提供可靠的响应大小时，读取进度随下载推进；否则显示已接收数据量和活动动画。附件按完成数量推进 60%～80%，消息排版推进 80%～95%，字体和代码排版推进至 99%。排版分小批次处理，使页面能持续刷新并响应取消。这是整体流程进度，不代表剩余时间；校验和排版完成后才确认 100%，完成后收起进度条。然后悬停或点击「导出」，选择 HTML 或 PDF。键盘操作可聚焦「导出」后按 Enter 或向下箭头展开，用方向键选择，按 Esc 收起。
   - **导出 → HTML**：下载单文件 HTML，包含样式、公式字体、成功读取的图片及文件附件。开头的问题目录可直接跳转。
   - **导出 → PDF**：一次点击按所选版式生成并下载 PDF，自动包含问题目录和每个问题的原生侧栏书签，保留正文、表格、公式和图形。不需要打开打印对话框或再次选择文件。打开 PDF 后，在 Chrome 侧栏选择「目录 / 书签」。
   - **导出菜单中的 A4 横向**默认不勾选，使用 A4 纵向。勾选后，预览与保存的 HTML 使用横向宽度，PDF 使用横向纸张；宽文本图也有更多空间。
   - 预览页在正文侧边显示固定的问题目录，点击可跳转，长目录可独立滚动；窄窗口下放在正文上方。保存的 HTML 和 PDF 保留开头的问题目录。每条消息后的「返回问题目录」链接已移除。
   - **导出 → PDF** 失败时才显示「备用 PDF 导出方式」，提供「打印 / 保存 PDF」和「添加 PDF 侧栏目录」。手动打印时选「另存为 PDF」、A4、「全部」页面及默认缩放，按需关闭页眉页脚、开启背景图形，再用「添加 PDF 侧栏目录」选择刚保存的文件。正常使用、重试成功或重新读取对话后隐藏这些备用操作。

读取时优先复用已打开的同一个对话页，不会跳转或关闭它。没有可复用页面时，才在后台打开临时的 ChatGPT 标签页；它仍出现在标签栏，但不会打断导出页。临时页在成功或取消后自动关闭，失败时保留以便检查登录或访问问题。读取结束不会切换你正在看的标签页，可取消读取后重试。

更新本地代码后，在扩展管理页点击扩展卡片的「重新加载」，接受可能出现的新增权限提示，并刷新已经打开的 ChatGPT 页和导出页。2.2 版新增 `debugger` 权限，用于直接生成 PDF。刷新 ChatGPT 页也会移除旧版遗留的网页按钮和状态提示。

## 手机阅读版 PDF（v3.2）

1. 打开对话，在「导出」菜单勾选「手机阅读版」，自动取消其他版式选项。版式勾选项互斥；均不勾选时使用 A4 纵向。
2. 预览切换为窄幅页面，点击「PDF」下载单独的 `-mobile.pdf` 文件，再发送到手机阅读。
3. 页面为 100 × 180 mm，左右边距 6 mm，上下边距 7 mm，正文 13 pt、问题 14 pt。保存的本地 HTML 也使用所选版式。
4. 普通代码保持 10.5 pt，视觉换行但不改写原文，长代码可按行分页。文本图和 ASCII 图保留空格与结构，按页面宽度和高度适配；特别宽或高的图仍可能需要放大。
5. 能放进一页的表格整体排版；超过一页高度的表格或单行仍可能跨页，浏览器无法把任意大的表格完整放在一张小页面中。保留开头的问题目录和原生 PDF 书签，手机是否显示书签入口取决于阅读器。
6. 自定义纸张优先使用直接「PDF」导出；备用打印对话框可能用选中的打印纸张覆盖尺寸。

## 汉王 N10 阅读版 PDF（v3.7）

1. 打开对话，在「导出」菜单勾选「汉王 N10（3:4）」，自动取消「A4 横向」和「手机阅读版」。取消勾选后恢复 A4 纵向。
2. 点击「PDF」，下载 `对话标题-hanwang-n10.pdf`，再传到阅读器。
3. 页面为 **150 × 200 mm**，采用 **3:4 竖屏比例**，四边 **10 mm 页边距**，正文 **12 pt**、问题 **13 pt**。预览与本地 HTML 同样采用此版式。
4. PDF 保留矢量文字、公式和问题／回答章节书签，不按屏幕像素分辨率生成截图。普通代码使用 10.5 pt，视觉换行但不改写原文，长代码可按行分页；文本图保留空格与结构，按页面可用宽度和高度适配。
5. 能放进一页的表格整体排版，超过一页高度的表格或单行仍可能跨页。特别大的文本图可能需要放大。直接「PDF」导出保留自定义尺寸；手动打印可能覆盖纸张尺寸。

## 阅读界面（v3.1）

- 未打开对话时，显示链接输入框和本地对话列表。
- 顶部本地版本和本地对话列表显示本地快照的保存时间，精确到秒，使用浏览器所在时区。
- 打开对话后，输入面板自动收起。顶部只显示对话标题、消息及问题数量、「对话列表」「更新对话」「批注信息」「导出」。
- 「对话列表」面板提供链接和本地对话；「备份与恢复」按需展开。点击「返回阅读」、按 Esc 或点击面板外部即可收起，正文位置不变。
- 「批注信息」打开已保存的批注列表；添加时先选中正文文字，再使用文字旁的小操作栏。
- 「导出」菜单包含 HTML、PDF、「A4 横向」「手机阅读版」和「汉王 N10（3:4）」选项。三个勾选项互斥；均不勾选时使用 A4 纵向。版式同时影响预览和导出文件。
- 备份及导出成功提示会在几秒后消失；错误提示保留。正常读取或恢复后，不在正文上方保留完成横幅。

## 每条消息的时间（v3.6）

每条问题和回答在标签旁显示创建时间，使用浏览器所在时区，精确到秒。时间来自 ChatGPT 的消息数据，并保留在本地快照、JSON 备份、本地 HTML 和 PDF 中。没有有效创建时间的消息不显示时间，也不会使用本地快照保存时间代替。

重新加载扩展并刷新阅读器后，旧版保存的对话需要点击一次「更新对话」补齐消息时间。仅重新打开旧快照无法恢复此前未保存的时间；已有批注仍然保留。

## 回答章节目录（v3.5）

预览页侧栏、离线 HTML 目录和 PDF 书签统一显示「问题 → 回答章节」层级。优先识别成组、顺序递增的章节编号，例如「一、二、三」「1. / 2.」、括号编号、第几章或罗马数字。支持 Markdown 标题，以及独立短段落中的编号标题，包括整行粗体。编号章节之后同层级的「最后：阅读建议」等无编号章节也会保留。开头单独的回答总标题，在后面存在章节时跳过；没有编号或编号不一致时，根据去掉总标题后的最外层标题选择章节。更深的子标题保留在正文中，引用、列表、代码示例和排版图形不加入目录。同一问题的多个回答共用章节列表，重复标题也有独立跳转位置。

正文保留标题中的格式，目录使用纯文字，去掉引用控件和重复的公式文字。重新打开已有本地快照时会自动生成新目录，无需重新联网读取。已导出的 PDF 或 HTML 需要重新导出才能包含新目录；较长的打印目录可连续跨页。

## 管理本地对话（v3.3）

打开「对话列表」，可查看每个对话的本地数据大小，以及全部对话的总大小。统计包含正文、内嵌附件和批注，并随当前页或其他阅读器标签页的数据变更自动更新。显示的是序列化 UTF-8 数据的估算大小；数据库索引、浏览器开销和磁盘压缩会影响实际磁盘占用。已删除批注保留的删除记录仍会计入大小，删除整个对话时一并清理。

点击某个对话右侧的「删除」并确认，将同时清理其本地快照、附件、划线和评论，ChatGPT 原始对话和已下载文件不受影响。删除当前阅读的对话会返回列表；删除其他对话会保留当前阅读位置及评论草稿。当前对话有未保存评论时，会先提示确认。再次打开已删除对话的链接会重新读取；恢复之前的 JSON 备份可恢复该对话和备份中的批注。

兼容已有本地数据和第 1 版 JSON 备份。数据库升级时仅计算一次旧记录的大小，此后刷新列表只读取元数据索引，无需加载完整正文和附件。

## 本地阅读器、划线与评论（v3）

1. 首次读取时，将通过完整性校验的对话及成功内嵌的附件保存到插件的本地 IndexedDB。
2. 在同一条问题或回答内选中文字，点击「划线」立即保存；或点击「评论」，输入内容后点击「保存评论」。支持段落、标题、列表、表格和代码中的文字，暂不支持公式、SVG 图形、引用和附件标签。
3. 打开对话后默认展开右侧「批注信息」，点击顶部「批注信息」可收起或重新展开，点击正文中的划线也可打开。列表按批注在当前正文中的位置排列，同一位置按创建时间排列。无法恢复原文位置时使用保存的文字偏移；所属消息已不存在的批注置于末尾。点击批注中的原文摘录可跳回对应位置；可编辑评论或删除划线及评论。重叠划线保留原文和排版结构。
4. 重新打开同一对话链接，或点击「对话列表 → 本地对话」中的标题，优先读取本地快照并恢复批注，无需访问 ChatGPT，支持离线阅读。成功打开对话后会同步阅读器地址，刷新时重新打开当前选择的对话。切换对话会清除上一个对话的章节定位，更新同一对话则保留。需要最新内容时，点击顶部工具栏的「更新对话」，再使用当前浏览器中的 ChatGPT 登录态读取最新分支。
5. 批注按对话和消息 ID 保存，并结合原文、前后文、文字偏移和消息文本摘要定位。如果消息被删除、重新生成或变化后无法可靠匹配，批注在列表中标记「原文已变化」，仍保留原文摘录和评论，不会贴到另一条消息上。
6. 展开「对话列表 → 备份与恢复」。「备份本地数据」下载包含所有本地对话、附件和批注的 JSON 文件。「恢复备份」先校验，再整批合并，保留较新的快照和批注修改。删除记录会保留，恢复旧备份不会复活已删除的批注。备份文件上限为 100 MiB。

阅读时左侧问题目录继续保留。宽窗口下，批注面板显示在正文右侧；较小窗口下，作为右侧浮动面板展开。HTML 和 PDF 导出原始对话，不包含阅读器控件和批注；批注通过 JSON 备份保存。单独打开已导出的 HTML 文件不具备插件阅读器的编辑功能。

数据保存在当前浏览器用户配置和当前扩展安装中，不自动跨设备同步。重新加载同一个已安装扩展会保留数据。**卸载扩展、清空扩展存储、变更扩展 ID 或移动未打包扩展目录之前，请先备份。** 备份文件包含私人对话和评论。写入失败会明确提示，评论保存失败时保留草稿供重试或复制。多个阅读器标签页会同步已保存的批注；编辑冲突会保留草稿并提示原因。

### 正文目录与 PDF 侧栏目录的区别

开头的目录是一页可点击的正文链接；侧栏目录则是原生 PDF 书签。「导出 → PDF」会自动生成两者：Chrome 将当前插件导出页直接渲染为 PDF，插件再使用 PDF 中的精确跳转目标写入问题书签。全程在本机完成，PDF 渲染不会打开额外标签页。

渲染期间 Chrome 可能显示调试提示。扩展只连接自己的导出页，读取 PDF 数据后立即断开，出错时也会尝试清理连接；不连接 ChatGPT 或其他浏览标签页。直接导出失败时，可先关闭导出页的开发者工具再重试，浏览器策略或其他调试器也可能阻止连接。失败后会显示手动打印和添加目录的备用操作。

使用备用的「添加 PDF 侧栏目录」时，请保持同一个对话已读取。扩展会校验原始对话链接、所有问题及回答标题的跳转目标，以及其引用的页面。请使用 Chrome 内置的「另存为 PDF」保存「全部」页面；系统 PDF 打印机可能丢失跳转目标。旧版文件只有保留当前预览所需的全部跳转目标时才可补目录。如果当前预览包含回答标题，v3.4 之前生成的 PDF 需要重新导出以加入这些目标。章节选择规则更新，或导出后编辑了问题、重新生成了回答时，请重新保存 PDF，以匹配当前预览的跳转目标。不支持加密文件或超过 100 MiB 的 PDF。

## 为什么不会受页面懒加载影响

v2 不再把「目前出现在 DOM 中的消息」当作完整对话。它利用当前浏览器中的 ChatGPT 登录状态读取对话数据，然后沿 `current_node → parent → 根节点` 重建当前分支，再按时间顺序生成文件。

- 不需要滚到顶部，不需要等待旧消息渲染，也不会因为页面回收离屏消息而遗漏正文。
- 遇到缺失父节点、循环、明确的分页标志、无法确定分支或正在生成的消息，会显示错误，不生成声称完整的文件。
- 导出页检查消息数、问题数与实际生成的正文段落是否一致。
- 「完整」指服务端返回的当前分支中可见的用户与助手消息，含助手阶段性回复；不包含系统指令、内部分析、工具调用，或编辑/重新生成后未选中的其他分支。
- 消息链校验不能证明 ChatGPT 服务端从未丢失历史数据；删除的消息、无权访问的内容无法恢复。

## 格式与附件

截至 **v3.5** 的渲染和目录更新也适用于已保存的本地对话：在 `chrome://extensions` 重新加载扩展，再刷新已打开的阅读器页面即可，不必重新读取对话。本地对话和批注仍保存在本地存储中。

- 按原始 Markdown 排版，保留标题、粗体、列表、引用、表格、链接、代码块及公式。
- 将 ChatGPT 的方框、网格、行、表格、标题、说明、徽标和箭头标签，以及基础 SVG 图形转换为静态布局，预览、PDF 和离线 HTML 均保留。表格组件（`table-row`、`table-cell`）转换成标准 HTML 表格，`<escape>` 保留比较符号等字面字符。支持基于字面量数组（包括对象数组与字段读取）的有限循环、数值运算与条件排版，以及 `gap=1` 等不带引号的数值属性、有限像素尺寸、小数 flex、四角圆角对象和大小写不同的组件名。支持有限的 `Array.from({length:16},(_,i)=>i)` 恒等范围写法和字面量数组成员判断；不执行 JavaScript，仅接受指定的布局和 SVG 属性，代码示例中的标签仍作为源码显示。
- `<Link url="..." title="..."/>` 转成带标题的 HTTP(S) 链接，同时识别 `<Cite>` 和 `<cite>` 引用。
- 自闭合的 `<Entity category="..." value="..." disambig="..."/>` 实体组件显示为 `value` 中的名称，保留周围的标题、加粗、链接及表格格式；分类和消歧属性不混入正文。名称按纯文本显示，代码示例中的实体标签保留原文。
- JSON 格式的 `<Chart content={...}/>` 柱状图转成静态分组条形图，保留各分类、系列名称和准确数值。其他图表类型或负值数据改用数据表格。无效或不支持的数据保留为可读源码；不加载图表脚本或外部运行环境。
- A4 版式中的代码和文本图使用等宽字体，保留空格、Tab 和换行，禁止强制折行。宽块按 A4 可用宽度缩小字号，短块尽量整块分页；超过一页的块仍可能分页。
- 可识别部分未包在代码围栏中的框线文本图，并按原样放进等宽块。
- 中英文正文优先使用系统中文字体；中文等宽字符依赖系统字体回退，源图本身的对齐问题不会自动重画。
- A4 打印样式包含标题与后文的分页约束和孤行控制；能容纳一页的表格整体分页，不在中间拆开。超过一整页的长表格仍会分页，重复表头，并尽量避免拆分表格行和图片。
- KaTeX 在本地渲染公式，单文件 HTML 内嵌公式字体，离线不需要 CDN。
- 原站的引用组件（包括 `<Cite ref="..."/>`、`<cite refs={...}/>` 和旧版引用标记）转成「来源」链接，并在相应消息末尾列出来源。单个引用支持带引号及花括号的字符串、大小写变化和属性换行。没有来源网址的引用在预览、离线 HTML 和 PDF 中直接隐藏。代码示例中的引用标签保留原文；不复制 ChatGPT 操作按钮、反馈工具栏等界面。
- 能下载的附件内嵌在 HTML 中，非图片附件在正文提供下载链接；PDF 只显示附件说明，不把附件内容作为 PDF 内置附件。
- 读取不到的图片、音视频或特殊组件会在正文明确标注，并在导出状态中报告。正文消息完整不等于所有特殊附件都已成功转换。

## 权限与数据处理

扩展申请 `scripting`、`debugger` 和 `chatgpt.com` / `chat.openai.com` 网站访问权限。`debugger` 用于一键生成 PDF，Chrome 不允许把它声明为可选权限（[Chrome 权限说明](https://developer.chrome.com/docs/extensions/reference/api/permissions)）。这是较强的浏览器权限；实现中仅在导出 PDF 时连接本扩展自己的 `print.html` 标签页，并在结束后尝试断开连接，不连接 ChatGPT 或其他浏览标签页。

扩展在 ChatGPT 内容脚本中使用当前 ChatGPT 登录会话，临时凭据仅留在读取函数内存中，不写入磁盘、扩展存储、HTML、PDF 或日志，也不发送给其他网站。第三方图片下载不携带该凭据。

正文在本机排版，没有上传服务。Markdown 的原始 HTML 不执行，公式启用 `trust: false`。离线 HTML 禁止脚本，字体和图片使用内嵌数据；点击来源链接仍会打开对应网站。

阅读器在扩展自身的 IndexedDB 中保存对话快照和批注，不新增浏览器权限。快照只保留文档所需字段，不保存登录凭据或任意接口元数据。评论始终按纯文本显示，从备份恢复后也不会执行其中的 HTML。

## 开发与调试

- 无法打开导出页：确认扩展开启，然后使用 Chrome「扩展程序」菜单或固定在工具栏上的图标。
- 导出页地址已带链接但输入框为空：重新加载扩展并刷新导出页。新版先填入链接，再读取最新的本地语言文件，避免 Chrome 缓存的旧文案中断自动读取；初始化失败也会在状态区显示原因。
- 读取失败：确认在安装插件的同一 Chrome 用户配置中已登录 ChatGPT，且能手动打开该链接。401/403/404 也可能来自权限、过期会话或网页接口变化。
- 扩展管理页 → 扩展卡片「错误」查看加载错误；「Service Worker」查看入口脚本错误。
- 导出页右键「检查」查看排版/下载错误；临时 ChatGPT 页开发者工具查看读取接口状态。不要分享包含登录凭据的请求头或未脱敏网络记录。
- 页面一直「正在加载更早的消息」不妨碍新版读取完整消息链；若完整接口也超时，会明确报错。
- 无需编译。可以用 `node --check` 检查根目录各 `.js` 的语法；不要对 HTML 使用该命令。
- 开发时安装 Node.js 18 或更高版本，然后在项目目录运行：

```bash
npm ci
npm test
```

测试使用 Node.js 内置测试框架、已打包的 PDF 库，以及仅用于开发的 JSDOM 和 fake-indexeddb。运行扩展不需要安装这些测试依赖。覆盖消息链与分支校验、链接入口、进度和取消、标签页管理、PDF 书签与正文保留；阅读器测试涵盖真实 DOM 文字范围、重叠划线、表格和代码结构、关闭重开后的 IndexedDB 恢复、离线读取、主动更新、评论编辑与删除、保存失败、跨标签页冲突、备份校验及事务合并、干净 HTML 导出。修改界面和打印样式后，还需要在 Chrome 中检查实际预览。

## 已知限制

1. 使用 ChatGPT **网页的未公开接口**，不是承诺稳定的官方 API。网站升级可能需要更新适配层；不需要 OpenAI API Key。
2. 私有链接必须属于或可被当前登录账号访问。共享链接的数据结构也会变，若无法校验会拒绝导出；本次实际验证使用私有 `/c/` 链接。
3. 当前只导出已选中的分支；不合并历史的替代回答或编辑分支，也不提取内部分析与工具日志。
4. 格式来自原始 Markdown，尽量保持阅读结构；不是网页像素级复制。代码暂未做语法高亮，Mermaid 保留源码；图表交互不会保留，支持的 JSON 图表转换成静态条形图或数据表格；其他交互组件、Canvas、视频播放器等不保证静态还原。
5. 单个内嵌附件上限 20 MiB，总下载附件上限 35 MiB。超过限制会保留提示。下载权限、跨域限制、附件过期都可能导致图片或文件无法内嵌。极大对话还受 Chrome 内存及消息大小限制。
6. A4 版式中代码行极宽时会缩小字号；横向 A4 通常更合适。浏览器对超长代码、超高表格行和公式的分页仍有自身限制。
7. 一键 PDF 导出需要 Chrome 调试权限，可能被企业策略、其他调试器或导出页的开发者工具阻止。保存路径由浏览器下载设置决定。手动打印功能仍可用，但需要另行补书签。不同 PDF 阅读器是否自动打开书签侧栏可能不同。
8. 批注暂时支持单条消息内的文字和一种划线颜色；没有云同步，不能在独立 HTML/PDF 中编辑批注，也不能对公式和 SVG 内部划线。缺失或歧义原文的批注保留在批注面板中。
9. 本地保存受浏览器磁盘配额限制。快照保存失败时仍可阅读和导出，但不能新增批注。JSON 备份文件上限为 100 MiB。
