Export a complete ChatGPT conversation

Enter a conversation link to create a PDF or a single HTML file with a question index.

Private conversations use your ChatGPT login session in this browser. Only the selected branch is read, including all its user and assistant messages from beginning to end.

Waiting for a conversation link.

Export → PDF creates sidebar bookmarks automatically, using the selected orientation and return-link setting. Chrome may show a debugging notice during export; the connection ends when rendering finishes.

Alternative PDF export

First use Print / Save PDF to save all pages with Chrome's Save as PDF. Then use Add PDF sidebar index to select that file and add question bookmarks locally.
